# Posy

CRM для цветочных магазинов: заказы, склад, клиенты, чаты, витрина, команда. Одна система для всех магазинов, у каждого магазина свои данные, название, цвет и точки.

Mirflowers (Актау) первый магазин на этой системе. Его данные и настройки (проект Firebase `mirflowersbase`, `shop.config.js`) сохранены и работают как раньше. Остальные магазины добавляются через `tools/new-shop.mjs` (см. `docs/NOVYJ_MAGAZIN.md`).

Где что: `DEPLOY.md` как загрузить и проверить, `PLAN_PLATFORMA.md` план и цены, `docs/CENA.md` расчёт цен, `PROJECT_6.md` полный разбор проекта, `sell.html` страница продажи.
