## 2. Что добавлено при подготовке

- **Выгрузка склада в CSV** (Настройки, «Резервная копия и экспорт», кнопка «Склад (CSV)»): остатки по точкам, цена продажи, у владельца ещё закупка и стоимость остатка. Нужна бухгалтеру и для сверки при переезде.
- **Скрипт полной выгрузки базы** `tools/export-firestore.cjs`: все коллекции и вложенные (сообщения чатов) в один файл. Это этап 0 из `docs/PLAN_VPS_KZ.md`. Проверен на эмуляторе: время, точки на карте, ссылки и вложенные документы сохраняются.
- В «Резервной копии и экспорте» уже было: полный отчёт в Excel (итоги, по точкам, по сотрудникам, заработок, расходы, заказы), заказы, клиенты, расходы в CSV и полная копия в JSON.

### Как сделать выгрузку базы
1. Один раз: `cd tools && npm install`.
2. Ключ сервисного аккаунта Firebase скачайте в Firebase Console (Настройки проекта, Сервисные аккаунты). Ключ храните только у себя, в чат и в письма не отправляйте.
3. Запуск: `GOOGLE_APPLICATION_CREDENTIALS=/путь/к/ключу.json node tools/export-firestore.cjs --project mirflowersbase --out export.jsonl`.
4. Файл содержит данные клиентов. Храните его в надёжном месте.

## 3. Что нельзя сделать до сервера

Переезд это не один шаг. Сейчас сайт работает с базой Google (Firebase), и сервера-замены ещё нет. По плану (`docs/PLAN_VPS_KZ.md`) работа занимает 6–8 недель:

| Этап | Что делается | Срок |
|---|---|---|
| 1. Ядро | сервер документов, подписки, транзакции, правила доступа | 2–3 недели |
| 2. Вход, фото, push | вход и сотрудники, фото, Web Push, сброс пароля | 1 неделя |
| 3. Функции | перенос 21 функции, WhatsApp, Instagram, копии | 1–2 недели |
| 4. Запуск | репетиция переноса данных, ночь переключения, откат | 1 неделя |

Начать этап 1 можно только после заказа VPS 25 ноября: нужен сервер для проверки.

## 5. Риски, которые видно сегодня
- Уведомления на iPhone приходят нестабильно: пока Firebase, это ограничение. После переезда на Web Push улучшится, но на iPhone нужен сайт, добавленный на экран «Домой».
- Скрипты сервера не проверены на реальной машине. Первый запуск делаем вместе, с запасом времени.
- Один человек в поддержке: нужен резервный человек, когда магазинов станет много.
