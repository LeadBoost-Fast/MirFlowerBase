# Если что-то сломалось: памятка для помощника

Для человека, который подключается к поддержке в первый раз. Читается за 10 минут. Пароли и ключи в этот файл не записываем никогда.

## 1. Как устроено сейчас (до переезда на PS.kz)
- **Сайт** лежит на GitHub Pages. Обновляется, когда изменения вливают в ветку `main` (через 1–2 минуты).
- **База, вход, фото, уведомления** работают в Firebase (Google), проект `mirflowersbase`.
- **Серверные функции** (уведомления, сообщения клиентам, копии) лежат в папке `functions/` и обновляются сами при вливании в `main`.
- **Подробности:** `DEPLOY.md`, `PROJECT_6.md`, план переезда `docs/PLAN_VPS_KZ.md`.

## 2. Доступы, которые нужны помощнику
Заполните список, но сами пароли не пишите, храните в менеджере паролей. Каждому человеку свой вход, общий пароль не используем.

| Что | Зачем | У кого сейчас |
|---|---|---|
| GitHub (репозиторий) | вернуть сайт на прошлую версию, смотреть проверки | (заполнить) |
| Firebase Console | база, копии, журнал функций | (заполнить) |
| PS.kz (после 25 ноября) | сервер | (заполнить) |
| Meta Business (после подключения) | WhatsApp и Instagram | (заполнить) |
| Домен (когда появится) | адрес сайта | (заполнить) |

## 3. Частые случаи

| Что случилось | Что делать |
|---|---|
| Сайт открывается пустым или с ошибкой после обновления | Закрыть вкладку и открыть заново. Если не помогло: GitHub, раздел Pull requests, последний влитый PR, кнопка **Revert**. Сайт вернётся к прошлой версии через 1–2 минуты |
| «Изменения не доходят», экран завис | Профиль, «Связь с базой», кнопка проверки. Если связь потеряна, переключить Wi-Fi и мобильную сеть, закрыть и открыть сайт. |
| Уведомления не приходят на iPhone | Сайт должен быть добавлен на экран «Домой», уведомления разрешены в настройках iPhone. Статья «Как включить уведомления на телефоне» в справке |
| Сотрудник забыл пароль | На экране входа «Забыли пароль», письмо уйдёт на его почту. Владелец может создать сотрудника заново |
| Магазин ошибся и удалил данные | Копия лежит в Firebase Storage: `backups/ГГГГ-ММ-ДД/<коллекция>.json` (каждую ночь в 03:00, хранится 14 дней). Автоматического восстановления нет, вернуть данные из файла может программист вручную |
| Нужна копия прямо сейчас | В приложении: Настройки, «Резервная копия и экспорт», «Копия на сервер сейчас» или «Резервная копия (JSON)». Полная выгрузка базы: `tools/export-firestore.cjs` |
| Нужны данные для бухгалтера | Настройки, «Резервная копия и экспорт»: отчёт в Excel, заказы, клиенты, расходы, склад (CSV) |
| Автотесты в GitHub красные | Не вливать PR. Открыть красную проверку, посмотреть, какая строка упала |

## 4. Чего не делаем без владельца
- Не удаляем данные магазина и не меняем правила доступа (`firestore.rules`) без владельца.
- Не просим у владельца пароли и коды в чате. Доступы выдаются через настройки сервисов.
- Не вливаем изменения в `main`, пока автотесты красные.

## 5. Когда звать программиста
Любая потеря данных, чужие данные на экране у магазина, сайт не работает дольше часа, письмо от Meta или PS.kz о нарушении.
